## 💫 About Me

Hi, I'm **Vinh**, a backend-focused software engineer with **1.5+ years of development experience**.

I mainly work with **Go, Java Spring Boot, and NestJS**, building backend services, REST APIs, and scalable systems with **PostgreSQL, MongoDB, and Redis**.

I also have hands-on experience with **Docker, CI/CD, Jenkins, GitHub Actions, Kubernetes (K3s), Linux, and cloud infrastructure**.

Throughout my projects and professional experience, I have worked on systems in **E-commerce, Education, SEO/SERP, Marketing Technology, and community platforms**, while also taking responsibility for backend architecture, technical leadership, deployment, and performance optimization.

I enjoy building software that is **simple, reliable, secure, observable, and easy to maintain**.
